# Story 4.1: Discord Notifications

## Status
Not Started

## Story
**As a** trader,
**I want** immediate Discord notifications for all trade events,
**so that** I can monitor my system remotely and stay informed of all trading activity.

## Acceptance Criteria

1. Webhook URL configured via environment variable (DISCORD_WEBHOOK_URL)
2. Entry notifications include: symbol, side, price, position size, timestamp, execution function used
3. Exit notifications include: symbol, side, price, P&L, exit reason (stop-loss/take-profit/manual)
4. Error notifications include: error type, symbol, attempted action, timestamp, error details
5. Notifications formatted with Discord markdown for readability (bold, colors, emojis)
6. Failed webhook posts logged but don't crash the system (graceful degradation)
7. Risk metrics included: position risk percentage, remaining portfolio capacity
8. Simulation mode clearly indicated in all notifications

### Component Architecture

**DiscordNotifier Interface:**
```python
class DiscordNotifier:
    """Discord webhook notification system."""
    
    async def send_entry_notification(self, trade_entry: TradeEntry, risk_metrics: RiskMetrics) -> bool:
        """Send trade entry notification with risk metrics."""
        
    async def send_exit_notification(self, trade_exit: TradeExit, pnl: Decimal, duration: timedelta) -> bool:
        """Send trade exit notification with P&L and performance data."""
        
    async def send_error_notification(self, error: TradingError, context: ErrorContext) -> bool:
        """Send error notification with actionable context."""
        
    async def send_system_notification(self, message: str, severity: NotificationSeverity) -> bool:
        """Send general system notifications (startup, shutdown, etc.)."""
```

### Notification Design Specifications

**Entry Notifications:**
- Green circle emoji (🟢) for entries
- Bold text for key information
- Risk metrics prominently displayed
- Execution function details for strategy tracking

**Exit Notifications:**
- Green (🟢) for profitable trades, red (🔴) for losses
- P&L both absolute and percentage
- Trade duration for performance analysis
- Exit reason for strategy refinement

**Error Notifications:**
- Warning emoji (⚠️) for recoverable errors
- Error emoji (❌) for critical failures
- Actionable recommendations where possible
- System state context for troubleshooting

**Simulation Indicators:**
- 📊 emoji for simulation mode notifications
- "SIMULATION" badge in notification titles
- Different color scheme for simulation notifications
- Clear distinction from live trading notifications

### Performance and Reliability

**Non-Blocking Design:**
- Notifications queued and sent asynchronously
- Trade execution never blocked by notification failures
- Background retry logic for failed webhook attempts

**Error Handling:**
- Graceful degradation when Discord is unavailable
- Comprehensive logging of notification failures
- Rate limiting respect for Discord webhook limits

**Configuration Options:**
- Notification verbosity levels (minimal, normal, verbose)
- Selective notification types (entries only, exits only, etc.)
- Simulation mode notification preferences
