# Story 4.2: Trade History Logging

## Status
Not Started

## Story
**As a** trader,
**I want** a permanent record of all trades with comprehensive metadata,
**so that** I can analyze my performance and refine my trading strategies.

## Acceptance Criteria

1. CSV file appends one row per completed trade with all relevant trade data
2. Trade fields include: timestamp, symbol, side, entry_price, exit_price, size, P&L, fees
3. Execution metadata logged: function used, timeframe, trigger level, confidence score
4. Separate monthly files (trades_YYYY_MM.csv format) with automatic file rotation
5. Trade performance metrics calculated: win rate, average win/loss, risk-adjusted returns
6. History queryable by date range, symbol, or performance criteria
7. Integration with existing logging infrastructure for trade event capture
8. Risk metrics included: risk percentage, portfolio impact at trade time
9. Simulation mode trades clearly distinguished from live trades

### Performance Analytics Specifications

**Core Metrics:**
- **Win Rate:** Percentage of profitable trades
- **Average Win/Loss:** Mean profit of winners vs mean loss of losers  
- **Profit Factor:** Gross profit ÷ gross loss
- **Maximum Drawdown:** Largest peak-to-trough decline
- **Sharpe Ratio:** Risk-adjusted return calculation

**Advanced Metrics:**
- **Expectancy:** Average trade profit including win rate
- **Recovery Factor:** Net profit ÷ maximum drawdown
- **Calmar Ratio:** Annualized return ÷ maximum drawdown
- **Ulcer Index:** Volatility of drawdown periods

**Risk Metrics:**
- **Value at Risk (VaR):** Potential loss at given confidence level
- **Risk-Return Ratio:** Return per unit of risk taken
- **Trade Frequency:** Average trades per day/week/month
- **Portfolio Utilization:** Average percentage of capital deployed
