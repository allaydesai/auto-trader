# Story 3.4: Simulation Mode

## Status
Not Started

## Story
**As a** trader,
**I want** a simulation mode that processes all logic without placing real orders,
**so that** I can test my strategies risk-free and validate system behavior.

## Acceptance Criteria

1. Environment variable controls simulation mode toggle (SIMULATION_MODE=true/false)
2. All execution logic runs normally (signals generated, risk checks performed)
3. Simulated orders use market prices but don't hit IBKR for actual execution
4. Simulated fills occur instantly at market price with configurable slippage
5. Portfolio state tracking works identically to live mode for risk calculations
6. All logging, notifications, and history recording operate normally
7. Clear simulation indicators in all output (logs, Discord, CLI status)
8. Ability to switch modes without code changes (environment variable only)

### Component Architecture

**SimulatedOrderManager Interface:**
```python
class SimulatedOrderManager:
    """Simulated order execution matching OrderManager interface."""
    
    async def place_bracket_order(self, entry: Order, stop: Order, target: Order) -> List[str]:
        """Simulate bracket order placement with immediate acknowledgment."""
        
    async def cancel_orders_for_symbol(self, symbol: str) -> List[str]:
        """Simulate order cancellation."""
        
    async def get_order_status(self, order_id: str) -> OrderStatus:
        """Return simulated order status."""
        
    async def simulate_fill(self, order: Order, market_price: Decimal) -> OrderFillEvent:
        """Generate realistic fill event with slippage."""
```

**Mode Detection and Dependency Injection:**
```python
class OrderManagerFactory:
    @staticmethod
    def create_order_manager(settings: Settings) -> Union[OrderManager, SimulatedOrderManager]:
        """Factory method to create appropriate order manager based on simulation mode."""
        if settings.simulation_mode:
            return SimulatedOrderManager(settings.simulation_config)
        else:
            return OrderManager(settings.ibkr_config)
```

**Simulation Configuration:**
```python
class SimulationConfig(BaseModel):
    """Configuration for simulation mode behavior."""
    slippage_stocks: Decimal = Decimal("0.0001")  # 0.01%
    slippage_futures: Decimal = Decimal("0.00005")  # 0.005%
    fill_delay_ms: int = 100  # Simulated network delay
    reject_probability: float = 0.02  # 2% chance of simulated rejection
    partial_fill_probability: float = 0.05  # 5% chance of partial fill
```
